## النشر على GitHub Pages
1. أنشئ مستودعًا عامًا جديدًا على GitHub.
2. فك ضغط الملف وارفع كل الملفات إلى جذر المستودع، وليس ملف ZIP نفسه.
3. افتح Settings → Pages.
4. اختر Deploy from a branch، ثم `main` و`/(root)`، ثم Save.
5. انتظر حتى يظهر رابط GitHub Pages.

## قبل تسليم المسابقة
- استبدل الصور العامة بصور المدرسة الحقيقية إذا كان مسموحًا.
- راجع أسماء المدرسة والعبارات مع إدارة المدرسة.
- نموذج التواصل وبوابة الطالب تجريبيان فقط؛ لا تجمع بيانات شخصية أو كلمات مرور.
- عدّل الأخبار بمعلومات حقيقية عن المدرسة.
